# العبقري لأنظمة الأمان والحماية — الموقع التعريفي

موقع تعريفي ثابت (Static) لشركة العبقري لأنظمة الأمان والحماية — العبقري Smart Home.
مرسى مطروح، شارع بورسعيد. «الأمان يأتي أولاً».

## المحتويات
- `index.html` — الصفحة الرئيسية (عربي RTL، متجاوبة مع الموبايل)
- `logo.png` — شعار الشركة

## النشر على GitHub Pages
1. من إعدادات المستودع: Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / `(root)` ثم Save
4. سيكون الموقع متاحًا على: `https://mostafaomar88.github.io/<repo-name>/`
