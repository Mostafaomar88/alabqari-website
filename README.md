# العبقري لأنظمة الأمان والحماية — الموقع التعريفي

موقع تعريفي من صفحة واحدة لشركة العبقري لأنظمة الأمان والحماية — العبقري Smart Home.
شارع بورسعيد، مرسى مطروح. «الأمان يأتي أولاً».

## المحتويات
- `index.html` — الموقع كاملًا في ملف واحد (عربي RTL، متجاوب مع الموبايل). الشعار مضمّن داخل الملف، وصور الأعمال تُعرض من صور صفحة النشاط على Google Maps.

## النشر على GitHub Pages
1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / `(root)` ثم Save
4. الموقع سيعمل على: `https://mostafaomar88.github.io/alabqari-website/`

ملاحظة: على الحساب المجاني يجب أن يكون الريبو Public حتى تعمل GitHub Pages.
